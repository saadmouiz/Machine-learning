Projet PACTE · Machine Learning · 4e année

Classification d’objets routiers par Machine Learning

Pour les véhicules autonomes — identification automatique d’usagers et de véhicules à partir d’une image.

Image → Voiture (92 %)  ·  Image → Piéton (87 %)

1. Problème

La perception d’un véhicule autonome localise puis nomme les objets. Nous traitons la deuxième étape : classer un crop d’objet routier.

3. Pipeline

  1. Nettoyage (objets difficiles / trop petits)
  2. Resize 64×64 + normalisation
  3. Split groupé par image source, environ 70 / 15 / 15
  4. Descripteurs HOG + couleur + LBP
  5. PCA 95 % puis k-NN / SVM / Random Forest
  6. Choix du modèle sur la validation, chiffres sur le test

4. Modèles comparés

k-NN

Baseline. Vote des voisins dans l’espace des descripteurs.

SVM RBF

Référence vision classique. Pondération des classes.

Random Forest

Ensemble d’arbres, robuste, importances de variables.

Métriques : Accuracy, Precision, Recall, F1 macro, matrices de confusion.

6. Classes difficiles

  • Moto ↔ cycliste : même géométrie deux-roues à basse résolution.
  • Bus ↔ voiture : même « boîte » véhicule, échelle ambiguë.
  • Piéton : poses, vêtements, occlusions.

Ces confusions sont réalistes pour une caméra seule, sans LiDAR ni tracking.

8. Conclusion

  • Un classifieur ML classique, après HOG, suffit à démontrer la brique « reconnaissance » d’une pile AV.
  • La comparaison multi-modèles + métriques macro respecte le cahier des charges.
  • Limite principale : pas de détection, pas de CNN, résolution 64×64.
  • Perspective : détecter puis classer en embarqué (pipeline deux étages).
